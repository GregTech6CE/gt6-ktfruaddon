# 02 单方块配方机器

- 状态：prep
- 依赖：01
- 文件范围：`Gt6KtfruMachines.java`，配方注册，对应的方块状态、模型和语言。占位拉晶炉和氢燃烧器在这张卡里撤掉或改成表内机器。
- 平台：NeoForge 1.21.1

## 背景

表面清单 20000–27553 是 GT 基础机器壳加 addon 配方图。配方图槽数在 `api/recipe/recipeMaps.java`。

## 目标

按清单落地这些单方块，每台一张配方图，能源种类按表：

| 段 | 机器 | 能 |
| --- | --- | --- |
| 20000 | 流体加热器 ×4 | HU，`FluidHeating` |
| 21000 | 光混合器 ×4 | RU，`LightMixer` |
| 22000 | 气体压缩机 ×5 | KU |
| 23000 | 电路组装机 ×5 | LU，`Assembler` |
| 23010 | 激光切割机 ×5 | LU，`LaserCutter` |
| 27000 | 热混合器 ×5 | EU，`HeatMixer` |
| 27030 | 电子设计器 ×5 | EU，`EDA` |
| 27040 | 缺陷检测器 ×5 | EU，`FlawDetector` |
| 27050 | 电动光混合器 ×5 | EU |
| 27500 | 晶圆测试器 ×5 | EU，`WaferTester` |
| 27510 | 晶圆涂布器 ×5 | EU，`WaferCoater` |
| 27542 | 超声混合器 ×3 | EU，`UltrasonicMixer` |

每档材料壳用源注册表里的材料名。合成先用能放下来的临时配方，正式产线配方跟对应的 `recipe/*.java`，档 D 的 AE 电路和 IC2 冷却液别名单独标出，不整段跳过。

## 接口缺口

矿机和虚空漏斗预先记在卡 05：它们不是 `AddonMachineContributor` 的配方机器。开工后每有一台对不上配方图、`BASIC` 壳或能源短名，把源注册名和缺的入口写在这里，并补到卡 05。

## 不做

- 矿机 27520、虚空漏斗 27550。它们不是配方机器，进卡 05。
- 源码里整段注释掉的 CVD 和超净洗浴。
- 多方块光刻、CNC、蒸馏。那是卡 04。
- 从 AGPL 源码拷类。槽数、电压和时间从源表重写。
