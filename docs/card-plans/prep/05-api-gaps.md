# 05 表面里接口接不住的部分

- 状态：prep
- 依赖：无
- 文件范围：这张卡。不改机器，除非某条被接口打开后另开实施卡。
- 平台：NeoForge 1.21.1

## 背景

这些条目在表面清单的 A/B 档里，所以不是 C 档那种「不要移植」。C 档本身不在任何实施卡里。

只记 GT6CE 附属接口里没有的东西。源码里已经有的声明不写在这里。对照的是 `addon/behavior-recipe-catalyst` 的 `9688dada`。API 仍是 0，模组版本仍是 0.0.0。

## 已有入口但不在这张卡实施

- 能量互转本身不是接口缺口。`BehaviorMachineDeclaration` 可以声明一种输入能量和另一种输出能量，`MachineBehaviorContext.emit` 可以把缓存推出去。API 没有现成的通用转换器、转换比例或源行为，仍需另写行为机器。源里的变压器、飞轮齿轮和轻型变换零件还是功能型结构零件，受下面功能零件的限制。
- 部分功能零件可以由控制器代做。太阳炉镜子的朝天判断、计算零件的数量统计，可以由控制器行为按零件坐标用 `level()` 去查，零件本身就是外壳。零件自己的储罐、物品槽、能量面或界面做不到，见下面。

## 先记着，不实施

- 掩膜对准机的第二种能量。灯模块收 LU，能量模块 31500 收 EU。`LARGE_RECIPE` 和行为机控制器都只收一种能量。`parts()` 的能量零件只往外推，`isEnergyAcceptingFrom` 恒为 false，`doInject` 返回 0，不能当第二个能量入口。要原样做，需要能接收能量的输入零件，或者控制器能声明两种输入能量。
- 燃料脱燃工厂同时收 EU 和 HU。EU 跑配方，HU 把温度加上去；温度离配方的最佳温度太远时，进度系数会变成负数，这一轮完不成。控制器只有一种输入能量，所以不能一边收 EU、一边收 HU。增强框架和化工反应管可以写成外壳，结构本身不是缺口。卡 04。
- 光学显微镜、电子显微镜和研究组装机的工作是研究任务，不是配方壳。玻璃和工作台可以用 `level().getBlockState` 自己查，布局里的 `air` 格要求那一格是空气。研究任务、研究数据库仍没有入口。卡 04。
- 零件外观号（`NBT_DESIGN`，例如矿处理输出墙的 7）。这是写在 GT 零件上的贴图序号。另注册一个 `parts()` 零件会换成另一块方块，而且没有这张贴图，看起来也不对。输出角色已经按结构格子生效。卡 04。
- 有自己 IO 或界面的零件：坩埚屏、需要单独接线的计算零件和无线计算零件，以及太阳炉镜子独立于结构、对着任意目标的那部分行为。`parts()` 只有外壳和能量零件，外壳没有储罐、能量、物品槽、界面，也不自己 tick。灯模块 31010–31013、平台 31005–31007、CNC 电机和刀头 31008–31009、油矿钻头 31014、热管 31003–31004、吸热器 31002、大型镜架和镜子 31050–31051 在源里是 `CommonPart`，就是外壳，不在这条。

## 不做

- 把 C 档内容（TFC 压板、小行星、符文扫描、火箭、环境校验）写进实施卡。
