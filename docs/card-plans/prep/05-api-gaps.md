# 05 表面里接口接不住的部分

- 状态：prep
- 依赖：无
- 文件范围：这张卡。不改机器，除非某条被接口打开后另开实施卡。
- 平台：NeoForge 1.21.1

## 背景

这些条目在表面清单的 A/B 档里，所以不是 C 档那种「不要移植」。C 档本身不在任何实施卡里。

只记 GT6CE 附属接口里没有的东西。源码里已经有的声明不写在这里。

## 先记着，不实施

- 特氟龙流体管、PVC 物品管。没有新管子入口。
- 飞轮箱六档，以及机械、电力、真空储 RU。行为机器每 tick 会把库存能量按额定输入排空，也不对外输出能量。
- 手摇马达、水车。行为机器能看见方块和坐标，但能量只进不出。
- 变压器、飞轮齿轮、轻型变换零件。没有能量转换，也没有附属零件入口。
- 新前缀：`flywheel`、大涡轮叶片、三级纯尘。`GregTechPrefixes` 只能查询已有前缀，附属不能声明新的。卡 01。
- 矿石前缀。`forms()` 只能点已有的生成前缀，`oreRaw` 对没有矿的材料仍然不合法。卡 01 的智金和二氧化钼因此没有矿。
- 矿机和虚空漏斗。范围扫描和虚空抽取不是配方图。
- 光刻模块、CNC 刀头、太阳炉镜子、研究桌、计算机集群和自有外壳。见卡 04 的右列。
- 压缩气罐和大型气罐阀，如果它们不只是燃料机储罐。
- 气体压缩机 `tankGasCompressedInputer`。要把气体推进压缩气罐，不是配方图，也不是 `BASIC` 壳。卡 02。
- 缺陷检测器把输出槽当输入搜。概率输出已经有了，这一半没有。卡 02。
- 编程电路 `ST.tag`。`AddonItems` 仍然只有 `stack(prefix, material, count)`。卡 06 因此空了 54 行：组装 38、热混合 8、激光 6、超声 2。
- 数量为 0 的催化剂。`AddonRecipes.Line` 没有不消耗标记，数量 0 会变成空栈。卡 06 的 46 行热混合因此没进。
- 气体电池 `FuelBattery`（10010–10011）。源里写进 `NBT_FUELMAP` 的是配方图 `ktfru.recipe.fuelbattery`：2 个电极物品、3 个流体输入、2 个流体输出，另要一只必须装满的电解液槽（4U 为 1000 mB，16U 为 4000 mB），EU 从顶面送出。`FuelGeneratorDeclaration` 只烧燃料图，没有物品槽。`BASIC` 机器吃能量，不按配方 EU 向外送。质子交换膜和 `BatteryPoleNickel` 这些是自定义物品。卡 03。
