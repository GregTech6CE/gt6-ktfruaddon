# 05 表面里接口接不住的部分

- 状态：prep
- 依赖：无
- 文件范围：这张卡。不改机器，除非某条被接口打开后另开实施卡。
- 平台：NeoForge 1.21.1

## 背景

这些条目在表面清单的 A/B 档里，所以不是 C 档那种「不要移植」。当前 API 8 没有入口。C 档本身不在任何实施卡里。

## 先记着，不实施

- 特氟龙流体管、PVC 物品管。没有新管子入口。
- 飞轮箱六档，以及机械、电力、真空储 RU。行为机器不把能量留到下一 tick。
- 手摇马达、水车。它们看玩家或邻水，不是燃料表。
- 变压器、飞轮齿轮、轻型变换零件。能量转换不在燃料模板里，也没有附属零件。
- 新前缀：`flywheel`、大涡轮叶片、三级纯尘。卡 01。
- 板和箔。接口能请求，但没有锭的材料会被启动检查拒绝。卡 01 的硅橡胶、丁苯橡胶、PEEK 因此没有板和箔。
- 矿石前缀。矿石不是生成前缀。卡 01 的智金和二氧化钼因此没有矿。
- 矿机和虚空漏斗。范围扫描和虚空抽取不是配方图。
- 光刻模块、CNC 刀头、太阳炉镜子、研究桌、计算机集群和自有外壳。见卡 04 的右列。
- 压缩气罐和大型气罐阀，如果它们不只是燃料机储罐。
- 气体压缩机 `tankGasCompressedInputer`。要把气体推进 `ICompressGasTank`，不是配方图，也不是 `BASIC` 壳。卡 02。
- 光混合器上方光照至少 14。`BASIC` 壳没有邻格光照门。卡 02。
- 缺陷检测器的概率双输出，以及把输出槽当输入搜。`AddonRecipes.Line` 没有概率。卡 02。卡 06 的 24 行激光切割是同一条缺口。
- 编程电路 `ST.tag`。想用 `AddonItems` 拿出这个物品，接口没有。卡 06 因此空了 54 行：组装 38、热混合 8、激光 6、超声 2。
- 数量为 0 的催化剂。源里用数量 0 表示不消耗的输入。`AddonRecipes.Line` 没有催化剂标记，数量 0 会变成空栈，整行被拒绝。卡 06 的 46 行热混合因此没进。
- 廉价超频。流体加热器、电子设计器、缺陷检测器、晶圆测试器源码带这个开关，`MachineDeclaration` 没有。卡 02。
- 单方块侧面输入输出掩码。`MachineDeclaration` 没有。默认六面物品和液体进出、能量六面、自动面为空，提示就是六面 `(no auto)`。卡 02。

## 不做

- 在附属里继承 GT 内部方块实体来绕过接口。
- 把 C 档内容（TFC 压板、小行星、符文扫描、火箭、环境校验）写进实施卡。
