# 04 现有零件能搭的多方块

- 状态：prep
- 依赖：01、02
- 排在卡 06 之后
- 文件范围：`MachineLayout`、对应的 `LARGE_RECIPE` 或燃料多方块、结构和语言
- 平台：NeoForge 1.21.1

## 背景

表面清单 30003 以后大多是多方块。接口只能用已经存在的 GT 零件名，没有附属外壳、端口、镜片或计算零件。全息投影仪（档 B）不搬，结构用 GT 的结构检查。

## 目标

先把控制器分成两列，再只做左列：

- 左列：结构可以全部写成现有零件，配方图已经在卡 02 或燃料模板里。候选是小型蒸馏塔、蒸馏塔、燃料脱燃工厂、矿处理系统，以及不要求新外壳的涡轮档。
- 右列：光刻机的灯模块和平台、CNC 刀头、太阳炉的镜子、计算机集群零件、自有墙和线圈。这些留在卡 05，不在这张卡里造假外壳充数。

左列里每台有结构、控制器和至少一条配方。

## 接口缺口

自有外壳、灯模块、刀头、镜子和计算零件预先记在卡 05。拆结构时，零件名不在现有 GT 零件里的，把控制器和那个零件写在这里，并补到卡 05。

## 不做

- 为了过结构检查去注册新零件。
- 研究树里点到 Advanced Rocketry 物品的解锁配方。
- 小行星矿机、火箭组装机、戴森球界面。
- 电磁坩埚控制器，直到只靠 API 8 的坩埚声明就能表达它的行为。TFC 受热接口不在范围内。

## 步骤

- [ ] 逐个读控制器的结构零件名，填左列和右列。
- [ ] 左列里先做最小的蒸馏塔：现有零件、一张蒸馏配方图、一条配方。
- [ ] 开发客户端里把结构搭起来并跑完那条配方。
