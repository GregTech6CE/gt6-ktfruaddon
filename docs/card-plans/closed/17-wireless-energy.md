# 17 无线能量塔

- 状态：closed
- 依赖：排在卡 16 之后
- 文件范围：两座塔和两只接收器的行为。坐标存在塔自己身上
- 平台：NeoForge 1.21.1

## 背景

塔在自己的 NBT 里记下接收器的坐标和维度，tick 时找到那块附属方块，把能量交给接收器。接收器再从自己的面送进旁边的电缆。GT 不负责远程传递。

## 方块

配对存在塔自己的链接表里。接收器右键用 U 盘写下自己的坐标、维度，以及是不是量子接收器。塔再用这根 U 盘把链接加进去。接收器从正面把缓存送进相邻电缆，包大小是它的输出值。注入只认内部面，也就是塔远程调用的那一面。

塔继承流体电池那套 `MultiBatteryBase`，每 200 tick 按 `LOSS_PERCENT / 100` 掉库存。这两台注册没有写 `LOSS_PERCENT`，所以这项是 0。链路上的损耗另算。

| 源 id | 类 | 材料 | 注册 |
| --- | --- | --- | --- |
| 30114 | `WirelessBatteryInductive` | Tungstensteel | EU。容量 367001600000。输入 2048–8192，安培 16。最多 8 条链接，距离 64，不跨维度。只认非量子接收器，只送 EU |
| 30115 | `WirelessBatteryQuantum` | Nq_522 | 容量 1468006400000。注册输入 1–32768，安培 64。类把单包上限改成没有上限，推荐值用注册上限。注册没有能量类型。库存为空时接受 `TD.Energy.ALL` 里的任意一种，一旦有库存就锁住这一种。最多 32 条链接。距离上限 0，类把它当成不限距离，损耗因此是 0。允许跨维度。只认量子接收器 |
| 31117 | `WirelessEnergyReceiver` | Tungstensteel | EU 8192，安培 4。外观 0，不是量子接收器 |
| 31118 | `WirelessEnergyReceiver` | Nq_522 | 输出 32768，安培 16，外观 1。外观 1 就是量子接收器，能量类型等第一次注入再定 |

感应塔的链路损耗是 `0.05 + 0.25 * min(1, 距离 / 64)`，再夹到 0–0.95。塔每送出 1 安培，扣的库存是 `ceil(接收器包大小 / (1 - 损耗))`。接收器实际入账的仍是它自己的包大小。

两座塔默认封存，活动扳手可以打开。接收器缓存上限是输出安培乘输出电压。

感应塔的层规则是 `AABBBCC`，每层 4×4。A 是 `XTTT / TCCT / TCCT / TTTT`，B 是 `OOOO / OCCO / OCCO / OOOO`，C 是 `WWWW / WBBW / WBBW / WWWW`。T 和 C 都是导体 31040，O 是线圈 18041，W 是能量输入墙 18006，B 是电池舱 31041，X 是控制器。

量子枢纽的层规则是 `ABCCCDDDD`，每层 5×5。A 是 `XWWSS / WSSSS / SSSSS / SSSSS / SSSSS`，B 全是墙，C 是 `SSSSS / SPPPS / SPRPS / SPPPS / SSSSS`，D 全是墙。W 是能量输入墙 18006，S 是同一面墙，P 是通道模块 31113，R 是读出线圈 31114。

## 不做

- 用 GT 电缆把塔和接收器连起来冒充无线。
- 感应塔按满包送达。损耗按上面的距离公式扣在塔的库存上。
- 让感应塔认量子接收器，或让量子枢纽认感应接收器。
