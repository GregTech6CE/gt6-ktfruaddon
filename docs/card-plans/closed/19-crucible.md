# 19 电磁坩埚

- 状态：closed
- 依赖：排在卡 18 之后。物品组成反查仍停在卡 05
- 文件范围：坩埚控制器和坩埚屏。不写假的物品材料查询
- 平台：NeoForge 1.21.1

## 背景

温度 `mTemp` 和熔融物 `mContent` 存在坩埚自己身上。出料走 `DummyCrucibleScreen` / `IDummyCrucibleMaterialProvider`。熔点可以读。把一件任意物品化进熔融物要知道它的材料和前缀，这条仍是 `OM.anydata_`，附属接口没有。

能写的是：控制器、坩埚屏、加热和按已知材料熔化。不能写的是从玩家投入的任意物品反查组成。没有这条之前，不做一个会认错材料的替代查询。

## 方块

| 源 id | 类 |
| --- | --- |
| 30032 | `ElectromagnetCrucible`，钛。注册没有能量。类默认收 EU，单包上限 1024，基础消耗 100，自身质量 3200，温度上限 32768，熔融物上限 `320 * U` |
| 31504 | 电磁坩埚屏 |

超过 1024 的包会让它爆炸，并吃掉这次注入。能量先累进 `mEnergy`。tick 末尾把 `mEnergy` 清零。能量低于 100 而且坩埚里有东西时，播放嘶嘶声，温度回到环境温度，熔融物清空。能量高于 100 而且温度没到上限时，温度加上 `(能量 - 100) / (1 + 总质量 * 1.66 / MultiTileEntityCrucible.KG_PER_ENERGY)`。然后按旧温度和新温度有没有跨过熔点，换成熔炼目标或凝固目标。最后每 tick 向环境温度降 0.2，不低于环境温度。

结构层规则 `ABBBC`，每层 5×5，偏移 -2、0、0。P 是坩埚屏 31504。X 是 GT 18006，角色是物品、流体和能量都进。C 是 GT 线圈 18041。空格是空位，类没有控制器谓词。

```text
A: " PPP " / "PXXXP" / " XXXP" / "PXXXP" / " PPP "
B: " XXX " / "XCCCX" / "XC CX" / "XCCCX" / " XXX "
C: " XXX " / "XXXXX" / "XXXXX" / "XXXXX" / " XXX "
```

投入物品仍走 `OM.anydata_`，停在卡 05。TFC 坩埚模型 32763–32764 是 `CrucibleModel`，不在这张卡。
