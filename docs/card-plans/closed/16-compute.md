# 16 计算机集群和无线计算

- 状态：closed
- 依赖：15
- 文件范围：这套检出里实际注册的计算控制器、用户、网线和两只集群零件
- 平台：NeoForge 1.21.1

## 背景

无线链路把对方的坐标和维度记在控制器自己的方块状态里。tick 时到那个世界看那一格是不是附属自己的方块。GT 不负责这段链路，也不把它当成能量输送。

这套检出没有 30058–30070、30079，也没有节点 32010–32043 和墙 31057–31095。`ControllerWireless` 没有 `ABA` 结构。1100、1102、1104 在这里是活注册，不是注释。

## 方块

1100–1105 的材料都是 StainlessSteel。注册只写了送出 512 EU。行为不凭空产生这 512 EU。底面收 256–1024 EU，正面可以送出 512 EU。

| 源 id | 类 | 方块 | 认入 |
| --- | --- | --- | --- |
| 1100 | `ControllerElectric` | `electric_controller` | 六个正交邻居里的控制器 |
| 1101 | `ControllerWireless` | `wireless_controller` | 同一维度、距离小于 512 的集群零件或控制器 |
| 1102 | `ControllerWired` | `wired_controller` | 正交邻居，或沿着 `network_cable` 走到的控制器 |
| 1103 | `TestUser` | `compute_user` | 无 |
| 1104 | `NetworkCable` | `network_cable` | 网线本身 |
| 1105 | `TileDreamBrain` | `dream_brain` | 无。不搬梦境测试 |

放大镜先在目标上记坐标，再在控制器上写入。坐标存在 `dim`、`x`、`y`、`z`。这套类把 `getDistanceFrom` 和 512 直接比较。卡上写这个方法返回的是距离平方，所以这里用平方和小于 `512 * 512`，也就是距离小于 512。

电控制器源类会顺着 GT 电线走。附属认不出那种电线，所以只留六个邻居。记在卡 05。

## 集群零件

| 源 id | 类 | 材料 | 槽 |
| --- | --- | --- | --- |
| 32005 | `MultiBlockPartComputeCluster` | Chromium | 4 |
| 32006 | `MultiBlockPartComputeClusterSimple` | StainlessSteel | 2 |

算力来自 `itemComputer`。这套检出没有那些物品，槽不接受放入，算力留在 0。零件没有能量注册，底面 1 EU 只为满足行为机。无线控制器认的就是这两只零件。
